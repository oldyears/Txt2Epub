# 异常章节 LLM 复查

用户已确认：规则初分后，由 DeepSeek 复查异常长章、长前言和分章过少的文件；先预览分割位置和上下文，确认后应用。

保留段落合并前的文本行及与当前预览的映射，复查不会重写正文。开头目录可作为模型阅读的上下文，不再通过合集目录直接推断卷标题。

用户从目录面板打开“复查异常章节”，选择待复查区段；界面说明将向 DeepSeek 发送所选区段的正文。使用现有浏览器本地 API 配置，支持进度与取消。请求按字符数和行数分块并保留边界重叠。

模型只返回所提供行的编号、原文、卷/章/正文类型和简短理由。校验编号范围、原文一致、类型有效、标题长度、重复冲突。空返回、截断、拒答和网络失败只影响复查；已完成的结果可预览，原目录和导出功能保留。

结果以复选列表展示建议标题和上下文。点击“应用所选建议”后一次性更新目录，保存书名作者、手动目录变更和仍能定位的和谐词替换。重新导入或重新处理后，旧复查结果失效。

通过中性样例测试前言误归类、标题无编号、跨分块边界、模型伪造位置、取消、失败、未确认不修改，以及确认后 EPUB 目录。私人原文件仅在本机做结构验证，不进入仓库。
