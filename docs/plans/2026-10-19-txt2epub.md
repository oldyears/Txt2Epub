# Txt2Epub Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 纯前端 PWA，把 txt / 混乱 epub 规范化为带正确卷章目录、去广告、去和谐的 EPUB3。

**Architecture:** `src/core` 全部是纯函数流水线（decode → clean → dictionary → classify → removeEmptyHeadings → mergeParagraphs → findCensorHits → sections → epub），`src/llm` 只负责 DeepSeek 调用，`src/ui` 是无框架 DOM 视图，单一数据源是 `Book.lines`。

**Tech Stack:** Vite, TypeScript (strict), JSZip, vite-plugin-pwa, Vitest + happy-dom, Playwright。

**硬约束（来自用户 CLAUDE.md）：** 函数 ≤ 20 行、参数 ≤ 2 个（超过用对象）、缩进 ≤ 3 层、不写解释意图的注释、不用异常做业务分支、重复立即抽象。

## 最终审查与验证（2026-10-19）

Task 1–14 已实现。Claude Code 会话因服务错误中断的最终整体审查已由 Codex 补完，并经独立复审。

本轮修复：

- EPUB 混排正文丢失：按块元素分隔后读取完整正文，保留标签外文字、嵌套引用及表格内容的阅读顺序。
- 不同卷同名短章节被误删：章节重复目录判定加入所属卷标题。
- 并发导入覆盖当前内容：文件处理期间阻止再次导入，完成后可正常打开下一个文件。
- 损坏 EPUB 静默丢章：spine 引用不存在的 manifest 项或没有可读正文时明确报错，并保留当前书籍和手动修改。

补充生产 PWA 测试：模拟 `/Txt2Epub/` 子目录部署，检查安装条件，等待 service worker 接管，断网重载后完成 GBK TXT 导入与 EPUB 下载。冒烟测试与 PWA 测试使用独立输出目录。

### Task 2: 类型与工具

**Files:** Create `src/core/types.ts`, `src/core/regex.ts`, `src/core/text.ts`; Test `tests/core/text.test.ts`

- `types.ts`：`LineKind = 'volume'|'chapter'|'body'`、`Line`、`CoverImage {data: Uint8Array; mediaType}`、`BookMeta {title; author; cover?}`、`SourceDoc {meta; rawLines}`、`Book {meta; lines}`、`CensorHit {lineIndex; start; end; raw}`、`DictEntry {from; to}`、`HeadingRules {volume; chapter; maxLength}`、`LlmConfig {apiKey; model}`、`Settings {heading; adPatterns; dictionary; llm}`
- `regex.ts`：`escapeRegExp(s)`、`safeRegExp(source, flags): RegExp | null`（用户输入的正则可能非法，唯一允许 try/catch 的地方之一）
- `text.ts`：`splitLines(text)` 按 `\r\n|\r|\n`；`parseFileName(name): {title; author}` 识别 `《书名》作者：某某.txt`，否则去扩展名为书名
- 测试：`splitLines('a\r\nb\rc\nd')` → 4 行；`parseFileName('《斗破苍穹》作者：天蚕土豆.txt')` → `{title:'斗破苍穹', author:'天蚕土豆'}`；`parseFileName('abc.txt')` → `{title:'abc', author:''}`
- Commit `feat(core): types and text utils`

### Task 3: 编码识别

**Files:** Create `src/core/decode.ts`; Test `tests/core/decode.test.ts`

- `decodeText(bytes: Uint8Array): string`：BOM(UTF-16LE/BE) → UTF-8 fatal → gb18030 兜底
- 测试：UTF-8 字节；GBK 字节 `[0xB5,0xDA,0xD2,0xBB,0xD5,0xC2]` → `第一章`（先用 `iconv -f utf-8 -t gbk` 核对字节）；UTF-16LE BOM
- Commit `feat(core): detect txt encoding`

### Task 4: 清洗

**Files:** Create `src/core/cleaner.ts`; Test `tests/core/cleaner.test.ts`

- `cleanRawLines(rawLines, adPatterns): string[]`：每条广告正则（`gi`）先从行内删除，再 `trim()`（已覆盖全角空格），丢弃空行
- 测试：全角缩进被去掉；`本章未完，请点击下一页继续阅读` 整行消失；行内 `www.abc.com` 被删；非法正则被忽略不报错
- Commit `feat(core): clean ads and whitespace`

### Task 5: 分章

**Files:** Create `src/core/splitter.ts`; Test `tests/core/splitter.test.ts`

- `classifyLines(texts, rules): Line[]`：长度 > maxLength 或以 `。，；、,;：:` 结尾 → body；否则先试卷正则再试章正则；标题经 `normalizeHeading` 在「第X章」后补一个空格
- `removeEmptyHeadings(lines): Line[]`：倒序扫描，标题的下一条保留行若是同级或更高级标题（卷=1、章=2）则删除——消除 txt 开头目录
- `mergeBrokenParagraphs(lines): Line[]`：相邻 body，前一行长度 ≥ 15 且不以 `。！？!?…”」』）)~—】"` 结尾 → 拼接
- 测试：`第1章重生` → chapter `第1章 重生`；`第一卷 风起` → volume；`第三章写完了。` → body；超长行 → body；目录块（卷1/章1/章2/卷1/章1/正文）只剩后半；断行合并与不合并各一例
- Commit `feat(core): heading detection and paragraph repair`

### Task 6: 去和谐（词典 + 检测）

**Files:** Create `src/core/censor.ts`; Test `tests/core/censor.test.ts`

- `createDictionaryApplier(entries): (text) => string`：预编译字面量正则（`gi`）
- `findCensorHits(lines): CensorHit[]`：`/[*＊]{2,}|(?<=\p{Script=Han})[*＊](?=\p{Script=Han})|[□■]+|×{2,}/gu`
- `applyFixes(lines, fixes: CensorFix[]): Line[]`，`CensorFix = {hit; replacement}`，同一行按 start 倒序拼接
- `hitContext(lines, hit): string`：前一行 + 本行（命中处包 `【】`）+ 后一行，各截 150 字
- 测试：`JING察` → `警察`；`习*平` 命中 1 处；`他**了` 命中；`口口声声` 不命中；同行两处修复位置正确
- Commit `feat(core): dictionary and censor detection`

### Task 8: 章节模型与 EPUB 写出

**Files:** Create `src/core/sections.ts`, `src/core/epubTemplates.ts`, `src/core/epubWriter.ts`; Test `tests/core/sections.test.ts`, `tests/core/epubWriter.test.ts`

- `Section {kind: 'preface'|'volume'|'chapter'; title; start; end}`；`buildSections(lines)`（首行为正文时生成「前言」）；`sectionParagraphs(lines, section)`；`buildToc(sections): TocNode[]`（章挂到前一个卷下）

### Task 9: EPUB 读取

**Files:** Create `src/core/epubReader.ts`, `src/core/txtReader.ts`; Test `tests/core/epubReader.test.ts`

- `readTxt({name, bytes}): SourceDoc`
- `readEpub(bytes): Promise<SourceDoc>`：container.xml → opf → manifest/spine（`getElementsByTagNameNS('*', …)`）→ 每个 xhtml 用 `text/html` 宽松解析、去 script/style、`br` → 换行、取叶子块元素文本；读 title/creator/cover。结构缺失抛 `EpubFormatError`（不可恢复失败）
- 测试：用 Task 8 的 `writeEpub` 写出再 `readEpub` 读回，行内容与元数据一致（round-trip）；缺 container.xml 抛 `EpubFormatError`
- Commit `feat(core): epub and txt readers`

### Task 10: DeepSeek 推断

**Files:** Create `src/llm/deepseek.ts`; Test `tests/llm/deepseek.test.ts`

- `suggestWords(queries: CensorQuery[], config: LlmConfig): Promise<Map<number, string>>`，`CensorQuery {id; context}`
- 40 条一批串行请求 `POST https://api.deepseek.com/chat/completions`，`response_format: {type:'json_object'}`，`max_tokens: 4096`；system prompt 含 "json" 字样与示例 `{"results":[{"id":1,"word":"原词"}]}`
- 空 content / 非法 JSON → 该批返回空（文档注明会偶发空返回）；HTTP 非 2xx → 抛 `LlmRequestError(status)`
- 测试：`vi.stubGlobal('fetch', …)` 验证请求头/体、41 条拆 2 批、空 content 不抛错、401 抛错
- Commit `feat(llm): deepseek suggestions`
